# Как пользоваться Menumancer

Гайды по разделам программы. Тот же гайд открывается в самой программе кнопкой «?» у заголовка раздела, а «Показать на экране» проводит по шагам подсветкой. Пошаговые гайды по задачам целиком (первый запуск, если что-то не работает, вопросы) — в [справочнике](../../handbook/ru/README.md).

- [Библиотека](library.md): Все ваши фоны для меню Доты. Здесь их ставят в игру, меняют музыку и то, что видно в меню, делятся фонами.
- [Создать](create.md): Новый фон за четыре шага: откуда взять видео, какой отрывок крутить, какая музыка и как собрать.
- [Меню Доты](menu.md): Своё оформление главного меню Доты. На виду основное: цвет кнопки «Играть», панель поиска игры и верхняя панель. Остальное (надписи, профиль, фигурки героев, страницы) лежит в «Дополнительно» с меткой «бета»: оно уже работает, но ещё дорабатывается. Меняется только оформление, через файл фона: в матче ничего не меняется, окно принятия игры, Dota Plus и осколки не трогаем.
- [Музыка](music.md): Плейлисты для фонов. Один плейлист можно поставить в разные фоны, а правки попадут во все.
- [Сцены](scenes.md): Живые фоны, которые рисует сама программа: северное сияние, космос, угли или ваша картинка с объёмом. В Доту попадает обычное видео с циклом без шва.
- [Настройки](settings.md): Всё, что нужно для сборки: где Дота, FFmpeg, с чего начинается новый фон, обновления и чистая Дота.
- [О программе](about.md): Версия, обновления, гайды, сообщить о проблеме, поддержка разработки и история изменений.
