# How to use Menumancer

Guides for each section of the app. The same guide opens in the app with the «?» button next to the section title, and «Show on screen» walks you through the steps with highlights.

- [Knihovna](library.md): Všechna vaše pozadí pro menu Doty. Tady je nainstalujete do hry, změníte jim hudbu a vzhled menu a sdílíte presety.
- [Vytvořit](create.md): Nové pozadí ve čtyřech krocích: odkud vzít video, který úsek se bude opakovat, jaká hudba a jak ho sestavit.
- [Úprava menu](menu.md): Vlastní vzhled hlavního menu Doty. Na očích je základ: barva tlačítka „Hrát“, panel hledání hry a horní lišta. Zbytek (nápisy, profil, figurky hrdinů, stránky) je v části „Další nastavení“ s označením beta: už funguje, ale ještě ho dolaďujeme. Mění se jen vzhled přes soubor modu: v zápase se nic nemění a okno přijetí hry, Dota Plus ani střepy nijak neměníme.
- [Hudba](music.md): Playlisty pro pozadí. Jeden playlist můžete dát do více pozadí a úpravy se projeví ve všech.
- [Nastavení](settings.md): Vše, co sestavení potřebuje: kde je Dota, FFmpeg, kvalita videa a co aplikace dělá.
- [O aplikaci](about.md): Verze, aktualizace, historie změn, všechny návody a jak podpořit vývoj.
