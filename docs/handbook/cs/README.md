# Příručka Menumanceru

Návody krok za krokem k tomu, co lidé v Menumanceru dělají. Jste tu poprvé? Začněte prvním.

[English](../en/README.md) · [Русский](../ru/README.md) · **Čeština**

1. [První spuštění](getting-started.md): stažení, první start, FFmpeg, otázka na dabing.
2. [První pozadí](first-background.md): od videa k plynulé smyčce s hudbou v menu Doty.
3. [Živé scény](live-scenes.md): polární záře, vesmír, vlastní obrázek s hloubkou, editor scén.
4. [Wallpaper Engine](wallpaper-engine.md): video tapety a scény z vašich odběrů a komu patří.
5. [Sdílení s přáteli](sharing.md): presety, ZIP a co smíte předávat.
6. [Řešení potíží](troubleshooting.md): pozadí není vidět, Dota se aktualizovala, menu se seká.
7. [Bezpečnost a otázky](faq.md): bany, co aplikace mění, varování antiviru, data.

Raději se díváte? Na YouTube je [videonávod](https://www.youtube.com/watch?v=7PoN7bGu5Gs) (rusky; YouTube umí titulky automaticky přeložit).

Hledáte jednu obrazovku? Každá sekce aplikace má vlastní krátký návod: [návody k sekcím](../../guide/cs/README.md). Stejné návody otevře v aplikaci tlačítko „?“ vedle názvu sekce.
