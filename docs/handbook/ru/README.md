# Справочник Menumancer

Пошаговые гайды по тому, что люди делают в Menumancer. Если вы здесь впервые, начните с первого.

[English](../en/README.md) · **Русский** · [Čeština](../cs/README.md)

1. [Первый запуск](getting-started.md): скачать, запустить, FFmpeg, вопрос про озвучку.
2. [Первый фон](first-background.md): от видео до цикла без шва с музыкой в меню Доты.
3. [Живые сцены](live-scenes.md): северное сияние, космос, своя картинка с объёмом, редактор сцен.
4. [Wallpaper Engine](wallpaper-engine.md): видео-обои и сцены из ваших подписок и чьи они.
5. [Как делиться с друзьями](sharing.md): пресеты, ZIP и что можно передавать.
6. [Если что-то не работает](troubleshooting.md): фон не виден, Дота обновилась, меню тормозит.
7. [Безопасность и вопросы](faq.md): баны, что меняет программа, антивирус, данные.

Удобнее смотреть? Есть [видео-гайд на YouTube](https://www.youtube.com/watch?v=7PoN7bGu5Gs).

Нужен один экран? У каждого раздела программы есть свой короткий гайд: [гайды по разделам](../../guide/ru/README.md). Те же гайды открываются в программе кнопкой «?» у заголовка раздела.
